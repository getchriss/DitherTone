# Dither Suite

dither console is a small tool trying to attempt to make art tools accessible to graphic designers, ui designers and
canva users to create dither art and retro-fi effects of text with chromatic filtering. 

users can upload media to make things reactive, images, draw primitive shapes, text upload images,
and manipulate layers similar to oher graphic software.
