03Frame▸

Cells split where the image has detail and stay large where it doesn't, so mark size carries information instead of being uniform. Error diffusion needs a regular lattice, so this grid quantises each cell on its own.

Rotating the screen is what stops overlapping grids from beating into moire. Polar reads the image in rings from the centre outward. Braille always uses a square grid at 0°.

Aspect compensates for glyph proportions. 0.55 suits monospace type, 1.00 gives square tiles.

04Tone▸

Step 1 is shadow, the last step is highlight. Glyph ramps are resampled evenly to match, so this governs every mode.

05Screen▸

Applies to tiles, glyphs, braille and hatching alike. Set the two apart and marks grow across the tone range, which is how a halftone screen behaves. Randomise blends each mark toward a random size somewhere between the two, so at 100% tone no longer sets size at all.

Edge detection substitutes directional marks (| / - \) along contours, or rotates tiles to follow them.

Every mark orients to the form using the structure tensor of the image, then tone adds hatch layers the way an engraver does: one direction, then its cross, then the diagonals.

Neighbouring marks bleed into each other and are re-hardened, so anything close enough fuses into one body. Threshold sets how near counts as touching. Cell wall outlines each blob in the second ink, which is where it starts looking like foam.

07Tiles▸

Each character becomes one tone step, left to right, shadow to highlight. Colour emoji keep their own colours if Tile ink is set to Original. Which emoji you get depends on the fonts on your machine.

Softens the alpha edge of the built-in sets so they sit against dithered output instead of cutting into it. Tiles that tile edge to edge keep hard outer boundaries regardless. Uploaded files are left as they are.

Slot 1 is the darkest step, the last slot is the lightest. Drop several files at once to fill slots in order. Empty slots print nothing.

Mark size across the tone range lives in section 05, since it governs glyphs and hatching too.

08Colour▸

Auto follows the colour mode above. Per tile gives every slot its own swatch. Original keeps whatever colours the file already has.

Transparent paper drops the background everywhere - preview, PNG and SVG. Whatever sits below the artwork in the layer stack shows through it.

Screens the image once per ink, each on its own rotated grid, and overprints them. CMYK multiplies, so it wants light paper; RGB screens, so it wants dark. Angle spread scales the classic 15/75/0/45 offsets, and nudging registration off is where it starts looking like a real press.

Hues are drawn from the chosen harmony around one random base. Paper stays desaturated at one end of the value scale, and the tile ramp keeps its shadow-to-highlight reading, so the image survives whatever hues come up.

09Press▸

The small errors that separate a print from a render. All of these are off by default.

Dot gain swells the midtones the way ink spreads into paper, which is why prints run darker than proofs. Variance jitters each mark a little so no two are identical.

11Motion▸

Presets write every control below, plus rotation snap in section 07, so nothing carries over from the last one. Tweak freely afterwards. The presets driving individual tiles only show in Tiles mode.

Audio reactiveoff

A Spotify or SoundCloud link can't be analysed directly - their players are sealed cross-origin frames, and Spotify is DRM protected on top. Play the track in another tab and use Capture tab audio, ticking Share tab audio in the picker. The microphone works with any source at all, including speakers.

Moves the halftone itself, so a still image comes alive. Stacks on top of video, capture or a spinning model. The recorder in section 12 captures it.

Per-tile motionTile 1

Each tone step animates on its own clock, so shadows and highlights can move differently. Stagger offsets each cell by its position, turning lockstep motion into a diagonal ripple. The Speed control above scales all of it.

12Output▸

Text export is available in Glyphs and Braille modes. Recording captures live output from a video, capture, spinning model or animated screen, at the plate's current pixel size - set columns and cell size before you start.
